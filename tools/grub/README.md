# Nimbus GRUB theme

`system/root/boot/grub2/themes/nimbus/` contains the Paper Dark theme payload:
a pure black background, off-white monospace text, gray selection, a countdown
bar and one line of keyboard help. The engine package installs it under
`/boot/grub2/themes/nimbus`; the `boot-theme` component activates it through
the inert `/etc/grub.d/36_paper_dark` drop-in.
See the [reference and native previews](../boot-theme/README.md).

The theme uses three bundled DejaVu Sans Mono PF2 fonts, generated by Fedora's
`grub2-mkfont` at 16, 20 and 24 pixels. `FONT-LICENSE` carries their license.
Integration must load these fonts before selecting the theme. Font and image
assets must be available under `/boot` before the encrypted root is unlocked.

The three PNG slices are generated with Python's standard library:

~~~sh
python3 -I -B tools/grub/assets.py
python3 -I -B tools/grub/assets.py --check
~~~

The [native GRUB theme format][theme] stretches center-only slices into plain
rectangles. No background photograph or icon set is required. Native previews
cover 1280x720 and 800x600, including scrolling additional entries and stopping
the countdown. Smaller modes and physical high-DPI displays remain unverified.
Long kernel titles can be clipped at narrow resolutions.

These assets only present GRUB's existing entries and countdown. Activation
preserves Fedora's BLS entries and EFI stub, leaves Fedora as the default, and
sets a visible five-second timeout that overrides `menu_auto_hide`. The drop-in
selects `gfxterm` and loads the three fonts only when Secure Boot is off,
because the shim-lock verifier refuses `loadfont`; otherwise GRUB's built-in
font is used; removal deletes the Nimbus marker
and regenerates Fedora's default configuration. Kernel graphics handoff is
unchanged. Older kernels, Windows discovery and encrypted-boot prompting still
need the VM boot trial recorded in [TASKS.md](../../docs/TASKS.md).

[theme]: https://www.gnu.org/software/grub/manual/grub/html_node/Theme-file-format.html
